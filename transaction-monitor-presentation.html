TransactionAlert 資料模型

@Entity
@Table(name = "transaction_alerts")
public class TransactionAlert {{
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long alertId;
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "transaction_id")
    private Transaction transaction;
    private String alertType;  // HIGH_AMOUNT, FREQUENT_TRANSACTIONS
    private String severity;   // HIGH, MEDIUM, LOW
    private LocalDateTime detectedAt;
    @Enumerated(EnumType.STRING)
    private AlertStatus status; // PENDING, RESOLVED
}}

HIGH

高額交易

  createAlert(

MEDIUM

頻繁交易

1 小時內超過 5 筆

long count = repository
  .countByCardIdAndTimeAfter(
    cardId, oneHourAgo);
if (count > 5) {{
  createAlert("FREQUENT");
}}
HIGH

重複交易

5 分鐘內相同金額與商店

List dups = 
  repository.findPotentialDuplicates(
    cardId, merchantId, 
    amount, fiveMinAgo);
if (!dups.isEmpty()) {{
  createAlert("DUPLICATE");

REST API 端點設計

查詢 API

  • GET /api/alerts - 查詢所有警示
  • GET /api/alerts/{{id}} - 查詢單筆警示
  • GET /api/alerts/type/{{type}} - 依類型查詢
  • GET /api/alerts/statistics - 統計資訊

管理 API

  • POST /api/alerts/detect - 手動觸發偵測
  • PUT /api/alerts/{{id}}/status - 更新狀態
  • PUT /api/alerts/{{id}}/resolve - 標記已處理
  • POST /api/alerts/search - 複合條件查詢
