核心模組

AlertDetectionService - 實作三種智能偵測規則：高額交易、頻繁交易、重複交易

TransactionAlert 資料模型

// 交易警示實體 - 記錄所有異常交易 @Entity @Table(name = "transaction_alerts") public class TransactionAlert { @Id @GeneratedValue private Long alertId; @ManyToOne private Transaction transaction; private String alertType; // HIGH_AMOUNT, FREQUENT, DUPLICATE private String severity; // HIGH, MEDIUM, LOW private LocalDateTime detectedAt; private String description; }

三種智能偵測規則

1
高額交易
2
頻繁交易
3
重複交易

規則 1：高額交易

單筆交易金額超過 50,000 元時觸發警示

規則 2：頻繁交易

同一卡片 1 小時內超過 5 筆交易

規則 3：重複交易

5 分鐘內相同金額、相同商店的交易

自動偵測機制

每筆新交易自動執行所有規則檢查

核心偵測邏輯

// 高額交易偵測 private TransactionAlert detectHighAmountTransaction(Transaction tx) { if (tx.getAmount().compareTo(HIGH_AMOUNT_THRESHOLD) > 0) { TransactionAlert alert = new TransactionAlert(); alert.setAlertType("HIGH_AMOUNT"); alert.setSeverity("HIGH"); alert.setDescription("交易金額超過閾值"); return alert; } return null; } // 頻繁交易偵測 - 使用時間窗口查詢 private TransactionAlert detectFrequentTransactions(Transaction tx) { LocalDateTime oneHourAgo = LocalDateTime.now().minusHours(1); long count = transactionRepository .countByCardIdAndTransactionTimeAfter(tx.getCard().getId(), oneHourAgo); return count > 5 ? createAlert("FREQUENT") : null; }
